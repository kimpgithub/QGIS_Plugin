    PostGIS에 행정리 경계를 편집/저장하는 종합 플러그인.

    파이프라인 (자동화):
    - Stage 1: 메인 PDF 좌표 자동 생성 (PDF 메타 기반, SIFT 폴백)
    - Stage 2: 스캔 OCR 식별 + SHP 회수 + PDF 라벨 sheet bbox
    - Stage 3: 분할 PDF 매칭 + TPS 워핑
    - Stage 4: 시트 모자이크 병합
    - Stage 5: 경계 검수
    - 미식별 보강 UI + 외부 JGW 가져오기 (수동 복구 지원)

    DB 작업 (PostGIS):
    - PG 연결 프로파일 관리
    - 행정리현황 엑셀 → ri_status 업서트
    - 전국 읍면동 리스트 + 더블클릭 맵 줌 + 워프 스캔 자동 로드
    - bnd_job_pg 자동 생성 + 편집 모드 제어
    - Split 시 새 피처에 adm_cd/ri_cd/ri_nm 자동 부여

    편집 툴바 (QGIS 3.40 호환):
    - Toggle Editing / Save / Split Features / Simplify
